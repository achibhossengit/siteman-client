# SiteMan Client

Frontend for SiteMan API.

## Stack

- Vite + React (JavaScript)
- Tailwind CSS + DaisyUI
- React Router
- TanStack Query
- Axios
- React Hook Form + Zod
- Lucide React

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview build |
| `npm run lint` | Oxlint |
